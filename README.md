A tiny program that writes one resignation letter to a text file. The letter
is exactly one line of at most 140 characters: a ghostwriter resigning, in
the first sentence that is actually hers.

## Run it

```sh
python3 main.py
```

It writes the letter to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
